========================================================
SEU PAINEL JÁ VIROU APLICATIVO (PWA) — SÓ SUBIR
========================================================

O index.html JÁ FOI MODIFICADO. Você não precisa mexer em
mais nada no código. As 3 linhas do PWA já estão dentro dele.

Este pacote tem 6 arquivos:
  - index.html   (JÁ com o PWA embutido — substitui o antigo)
  - manifest.json
  - service-worker.js
  - icon-192.png
  - icon-512.png
  - icon-512-maskable.png

--------------------------------------------------------
PASSO 1 — Subir os arquivos no GitHub
--------------------------------------------------------
No repositório "painel-oleo", envie os 6 arquivos
(Add file -> Upload files -> arraste os 6 -> Commit).
Quando perguntar, confirme SUBSTITUIR o index.html antigo.

Os ícones estão na cor verde da Fazenda Piracicaba (#0A5F3A),
combinando com o painel.

--------------------------------------------------------
PASSO 2 — Instalar o app
--------------------------------------------------------
Espere 1 ou 2 minutos e abra:
   https://mendoncaaves.github.io/painel-oleo/

CELULAR (Android/Chrome):
   Toque no aviso "Instalar aplicativo" / "Adicionar à tela
   inicial". O ícone da gota vai pra tela inicial e abre
   como app, sem barra de navegador.
   (iPhone/Safari: botão Compartilhar -> "Adicionar à Tela de Início".)

DESKTOP (Chrome/Edge):
   Clique no ícone de instalar na barra de endereço (monitor
   com seta) -> "Instalar". Vira um programa com janela própria.

--------------------------------------------------------
QUANDO ATUALIZAR O PAINEL NO FUTURO
--------------------------------------------------------
Ao mudar o index.html, abra o service-worker.js e troque a
versão do cache para forçar a atualização nos aparelhos:
   const CACHE_NOME = "painel-oleo-v1";  ->  "painel-oleo-v2"

--------------------------------------------------------
LEMBRETE SOBRE OS DADOS
--------------------------------------------------------
Cada aparelho ainda guarda seus próprios dados no navegador
(localStorage). Para todos verem os mesmos equipamentos e
trocas, o próximo passo é migrar os dados para o Azure.
